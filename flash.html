計步器韌體燒錄

給老師用：不用安裝任何軟體，用 Chrome 或 Edge 就能把正式韌體燒進板子。會自動判斷是 T-Display 還是 T-Display S3。

步驟

  1. 用 Chrome 或 Edge（電腦版）開這一頁。Safari、Firefox、手機都不行（沒有 Web Serial）。
  2. 用 USB 資料線（不是純充電線）把板子接上電腦。
  3. 按下面的「連接並燒錄」，在跳出的清單選板子（T-Display 會顯示 USB Single Serial 或 CH9102；T-Display S3 會顯示 USB JTAG/serial debug unit），按「連線」。
  4. 等進度條跑完（T-Display 約 1～2 分鐘、S3 約 30 秒），看到「燒錄完成」板子會自動重開機。






清單裡找不到板子？




板子怎麼處理


T-Display（ESP32，USB 晶片 CH9102）Windows：先到 WCH 官網安裝 CH343SER 驅動（含 CH9102），重新插拔。
macOS：多半免裝；若沒出現，安裝 CH34XSER_MAC 並在「系統設定 → 隱私權與安全性」允許。


T-Display S3（ESP32-S3，晶片內建 USB）不用裝驅動。若清單沒有或燒到一半斷線：按住 BOOT 鍵（USB 左邊那顆），再按一下側邊的 RST 小按鍵，放開 BOOT，板子進入燒錄模式後再按一次「連接並燒錄」。燒完按一下 RST 重開機。


兩種都適用換一條確定能傳資料的線；關掉 Arduino IDE 的序列埠監看視窗（它會占住連接埠）；USB 集線器有問題就改插電腦本體。





燒錄後


步數、設定存在板子的設定區，平常更新韌體不會清掉（除非勾了「先清除全部資料」）。接上電腦時板子會向電腦要時間；也可以到 模擬器頁 先熟悉操作。要改程式請用講義附錄的 Arduino IDE 步驟。
